# TV APK Installer

Русскоязычный Android-проект для управления установкой APK на Android TV.

## Текущий статус
Версия 0.1.0 — демонстрационный интерфейс и настройка CI-сборки. Реальное ADB-подключение и установка APK пока НЕ реализованы. Не используйте эту сборку как готовый установщик.

## Сборка
GitHub Actions запускается при push в `main` или вручную через Actions → «Собрать APK» → Run workflow.

## Совместимость
Цель — Android TV / Google TV и совместимые Android-системы. Hisense VIDAA не является Android и не устанавливает APK напрямую.
