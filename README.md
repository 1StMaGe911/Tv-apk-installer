# TV APK Installer

Русскоязычное Android-приложение для установки APK и обслуживания Android TV / Google TV устройств через ADB.

## Текущая версия

**0.8.7** — темы сохраняют персональные виджеты, кнопки Wi‑Fi/Inputs/Library, параметры входов и запуска ТВ; неизвестные будущие ключи конфигурации также не теряются. Точки восстановления привязываются к модели и отпечатку прошивки: восстановление на другом ТВ или после смены прошивки блокируется. **0.8.6** добавил выбор пакетов, проверенных для точного профиля модели, пакетное отключение после отдельного подтверждения и восстановление отключённых пакетов. Перед установкой темы сохраняется ZIP-копия прежнего оформления.

## Возможности

- Подключение к телевизору по Wi-Fi ADB и сохранение устройств.
- Прямое USB ADB через OTG для устройств, которые предоставляют стандартный ADB USB-интерфейс; установка выбранного APK по USB после системного разрешения и подтверждения RSA-ключа.
- Выбор APK и установка приложений; история установок и проверка обновлений.
- Управление пользовательскими приложениями: просмотр сведений, запуск, отключение, восстановление и удаление с подтверждением.
- Диагностика устройства: память, накопитель, батарея, время работы и сведения о прошивке.
- Инструменты Clean Your TV: каталог сведений о пакетах, профили моделей, выбор кандидатов, проверенных для точной модели (ask=false), пакетное отключение с повторной проверкой профиля и защита критичных компонентов; отключённые пакеты можно восстановить.
- Интеграция модулей Clean Your TV Launcher и Curtain из выбранного пользователем оригинального APK.
- Настройки Launcher, темы, обои и назначения кнопок пульта; опциональная поддержка HomeKeyService для отдельных пультов.
- Экспорт и восстановление конфигурации Launcher, ZIP-резервные копии с текущими обоями и коллекцией обоев, если файлы доступны через ADB/ThemeProvider.
- Пульт дистанционного управления через ADB keyevents.
- Резервное копирование настроек самого TV APK Installer и управление автозапуском там, где это поддерживает прошивка.

## Важные ограничения

- Приложение рассчитано на **Android TV, Google TV и совместимые Android-устройства** с доступным ADB.
- **Hisense VIDAA, Samsung Tizen и LG webOS — не Android**, поэтому это приложение не может управлять ими через Android ADB и не устанавливает на них Android APK.
- USB ADB требует, чтобы целевое устройство работало в USB device/peripheral mode и предоставляло интерфейс ADB (FF/42/01). Большинство обычных USB-портов телевизоров работают только в режиме HOST; в таком случае используй Wi-Fi ADB.
- Некоторые действия зависят от производителя, версии Android, прошивки, разрешений и наличия ADB. Не все команды поддерживаются каждым телевизором.
- Каталог пакетов и профили помогают выявлять кандидатов на очистку, но не гарантируют, что каждый пакет безопасно отключать. Проверяйте назначение; критические пакеты защищены, массовое отключение без подтверждения не выполняется.
- Интеграция Clean Your TV не означает полного переноса всего оригинального приложения. Полный откат системных настроек, все профили/каталог модулей и отдельные специфичные для прошивок функции ещё требуют переноса и проверки.
- ZIP-резервная копия включает конфигурацию и доступные файлы обоев; состав резервной копии зависит от того, какие файлы конкретная прошивка разрешает прочитать.

## Установка и релизы

Последний APK и история версий доступны в разделе [GitHub Releases](https://github.com/1StMaGe911/Tv-apk-installer/releases).

Сборки и журнал ошибок: [GitHub Actions](https://github.com/1StMaGe911/Tv-apk-installer/actions).

## Сборка из исходников

GitHub Actions запускается при push в ветку `main` или вручную через Actions → Build APK → Run workflow. Основная логика приложения находится в `app/src/main/java/ru/tvapk/installer/MainActivity.kt`.
